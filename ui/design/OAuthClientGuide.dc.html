the guide window
"Guide me on top of Google's console" opens this small window (Document Picture-in-Picture, in Chrome and Edge) that stays above Google's tab while you click there. it carries only the current step: its console link, instructions, copy controls, Back, Mark done and "Done, open step n". every console link reuses one named console tab, and step 7's file drop and paste work in here too. the UI's own tab follows.

in Firefox or Safari the same panel opens as a narrow side window, placed at the screen's right edge. if the browser blocks it: "Your browser blocked the window. Allow pop-ups for this site, or keep using this tab."

Check with Google and save
the file is read in the browser for its client ID, secret and project. a web application's file, or anything else, is refused before anything is sent, with a line naming what it holds. a project other than step 1's is named before saving. then the same check with Google as a paste.
after Google accepts: "Google accepted this client. Saved as mediated-mailbox-482113, its secret sealed." the primary button is "Connect your first account", or "Connect an account through {name}" once an account exists. a name another client holds, or new, is refused, and a client ID another client holds reads "This client is already set up as {name}". a refusal lists first "A client created in the last few minutes may not be active yet. Wait five minutes and press Check again."
why not just links
Google renames and moves console pages, and its deep links aren't documented as stable. each step names the page by its menu path under "Looks different?", so a link that lands elsewhere still gets you there.
