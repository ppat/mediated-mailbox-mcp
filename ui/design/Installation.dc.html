Getting started
Before you start
About 15 minutes. You need a Google account allowed to create Cloud projects, which need not be the mailbox, and the Gmail address to connect. Chrome or Edge keeps the guide on top of Google's console. Google warns that the app is unverified, which is expected.

the installation scope
routes outside /{account}: /setup, /setup/gmail/new, /setup/gmail/{client}, /setup/connect, /setup/policy. its own navigation, Setup · Base policy. no search, range or group-by, which belong to an account.
shows only installation records: each client's name, provider, client id and project id, each account's identifier, provider and client, and the base rules. never an account's state or counts, so nothing aggregates across accounts.

/ with no account lands here.
a client's row
name in mono, links to its setup at /setup/gmail/{name}. client id shortened, the full value on hover. accounts on it link to their Home, or "no account yet".
Remove is enabled only while no account connects through the client. it confirms: "Remove the client {name}? Its sealed secret is deleted here. The client itself stays in Google Cloud console, where you can delete it." and removes nothing else.
a provider with no client reads "No Gmail client yet", with Add a Gmail client.
other states
· nothing set up: item 1 is current. Connect reads cannot start yet, a dashed circle in faint text with no link, and the Accounts region carries no Connect control while Getting started shows. the base policy item stays optional, its title a live link.
· no base rule: item 2's status reads "No base rules yet · optional".
· once an account exists: Getting started is gone, and Accounts gains its own Connect an account, as above.
status is text plus a glyph: a filled check done, an open circle not started, an open circle in muted text optional, a dashed circle in faint text cannot start yet.
