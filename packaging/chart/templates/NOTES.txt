To reach it from this machine:

  kubectl --namespace {{ .Release.Namespace }} port-forward service/{{ $fullname }}-ui 8443:{{ .Values.ui.service.port }}

Set up an OAuth client, connect an account and import the policy through the UI. Then start backfill's first run:

  kubectl --namespace {{ .Release.Namespace }} create job --from=cronjob/{{ $fullname }}-backfill backfill-first-run

Each later release, and each change to the scanner's section, runs backfill again with no manual step.
